# 2차 메인 화면 변경 기록

## 기준 캡처에서 확인한 내용

- `review/round1/after/after-02-observe-problem.png`: 문제 상태에서도 8개 상태 카드가 상단을 차지하고 라이브 뷰는 좁은 열에 놓였으며, MOP 조작은 별도 하단 영역에 분리돼 있었다.
- `review/round1/after/after-01-observe-normal.png`: 기체·MOP·인터넷 연결 정보가 라이브 뷰에서 분리된 상태 영역에 이어져 한눈에 조종 화면과 연결 상태를 묶어 보기 어려웠다.
- `review/round1/after/after-08-observe-dark.png`: 다크 모드도 같은 카드형 정보 구조를 유지해, 모드가 바뀌어도 라이브 뷰가 작업 중심으로 읽히지 않았다.

## 재구성 및 중복 정리

- 조종 화면을 라이브 뷰가 전체 작업 영역을 차지하는 구성으로 바꿨다. 8개 상태는 왼쪽의 세로 상태 레일에 계약 순서대로 두고, MOP 전송 요약·AI 피드·증거 상태는 오른쪽 레일에 모았다. 영상 연결 컨트롤은 위쪽, MOP 연결·해제·재전송은 영상 위 하단 도크에 배치했다.
- 기체·MOP·인터넷을 반복하던 별도 사실 표를 없애고, 상태 레일에서 각각 독립된 항목으로 한 번씩 보이게 했다. 상태별 심각도와 다음 행동 문구는 그대로 유지했다.
- 조종 화면 안에서는 `사건 0건 — 정상 기록일 수 있음 / 안전 확인 아님`을 최근 요약 행 한 곳에서만 보여 준다. 시나리오를 전환하면 같은 행의 문구가 바뀐다.
- `[SIMULATED]`의 추가 반복이던 워드마크 보조 문구를 덜어냈다. 상단 표기와 영상·MOP·피드 등 시뮬레이션 데이터 출처 표시는 유지했다. 미동기화 건수는 왼쪽 상태 레일에 그대로 노출하고, 증거 화면의 목록·카운트도 보존했다.
- 조종 화면의 `RC 수신시각(근사)`는 상단 전역 고지 한 곳에 두고, Edge-monotonic 설명은 AI 피드 하단 한 곳에 뒀다. 다른 화면의 시간 계약 정보와 개별 기록 시각은 기존 기능을 위해 유지했다.
- 이전 관측 카드 배치에서 더 이상 쓰지 않는 CSS 규칙을 제거했다.

## 스크롤 목표

1920×1200 가로 화면용 규칙에서 조종 화면 높이를 뷰포트에 맞춰 제한하고, 라이브 뷰를 그 높이 전체에 펼친 뒤 양쪽 정보를 모서리 오버레이로 얹었다. 상태 레일은 넘칠 때만 내부 스크롤을 허용한다. 따라서 주요 운용 정보와 컨트롤이 한 화면에 들어오도록 구성했지만, 이번 세션에서 수정본을 렌더하지 않아 실제 픽셀 배치와 무스크롤 여부는 확인하지 않았다.

## 보존 및 확인 범위

- 여덟 상태 항목의 순서·심각도 표기·행동 의미, 세 연결 사실의 분리, 고정된 사건 0건 문구, `[SIMULATED]`, 수신시각 근사 고지, 미동기화 수를 보존했다.
- 관측·임무·비행 기록·증거/동기화·설정의 다섯 화면과 참조된 기존 조작 요소 및 설정 제출 컨트롤이 소스에 남아 있는 것을 확인했다.
- `ksi-safety-edge-field-shell.html`은 이름을 유지하며 스타일과 동작 코드를 포함한 단일 HTML이다. 최종 소스 SHA-256: `3d9663353db4374a6a0e41344bb89f2a5d30e6b89eed1c1b9b9cdf3b2da417a7`.

## 미검증 항목

수정본의 새 캡처는 만들지 않았다. 1920×1200에서의 실제 레일 높이와 내부 스크롤, 겹침·잘림, 낮/다크 모드 대비, 버튼 터치 영역이 화면에서 충분히 읽히는지는 하네스 렌더 후 확인해야 한다. 햇빛 아래 실제 RC Plus 2와 장갑 조작도 확인하지 않았다.
