## 수정 전 결함 목록

### R3-01 · P1 — 끊김 상태에서 복구 CTA가 도크 안에서 가장 덜 눈에 띔

- **화면/상태:** 조종(관측), 문제 시나리오.
- **관찰:** 왼쪽 상태 레일은 `MOP 링크 / 끊김 / 마지막 하트비트 18.4초 전 / 링크 연결 후 재전송 확인`을 문제 색으로 보여 준다. 그런데 아래 도크의 `MOP 연결 (Connect)` 버튼은 어두운 채움으로 어두운 도크에 놓이고, 덜 긴급한 `연결 해제`·`미확인 재전송`은 밝은 채움이다.
- **사용자 영향:** 짧은 시선에서 계약상 다음 조치인 연결이 먼저 잡히지 않고, 세 장갑 터치 중 잘못된 버튼을 고를 수 있다.
- **목표:** 링크 끊김일 때만 연결 버튼을 높은 대비의 문제-맥락 CTA로 강조하고, 정상 상태에서는 연결이 불필요하게 기본 조치처럼 보이지 않게 한다. 레이블·동작은 바꾸지 않는다.
- **상태:** 수정 전.

### R3-02 · P2 — 관측 보조 텍스트가 야외 빠른 스캔에 작음

- **화면/상태:** 조종(관측), 정상·문제·비행 없음·다크.
- **관찰:** 상태 라벨/세부값은 대략 12.5–12.8px, 행동 문구는 약 13.1px이며, 일부 보조 텔레메트리와 내비게이션 보조 라벨은 약 11–12px다. 화면에는 맞지만 7인치·햇빛·짧은 시선 조합에서 행동과 부가 사실을 구분해 읽는 부담이 있다.
- **사용자 영향:** 주 상태 값은 읽히지만, 수신 시각·근거·다음 조치의 작은 글자를 더 오래 응시해야 한다.
- **목표:** 관측에서 핵심 상태/행동/세부 텍스트를 조금 키우되 행 간 여백을 조정해 8개 상태·미동기화 수·핵심 조작이 한 화면에 계속 보이도록 한다.
- **상태:** 수정 전.

### R3-03 · P3 — 나머지 페이지 보조 정보와 조작의 상대 크기 일관성

- **화면/상태:** 임무 준비·비행 기록(검토)·증거/동기화·설정/개발.
- **관찰:** 각 페이지의 주요 제목, 48px 높이 버튼, 목록/수치 계층은 안정적이다. 푸터와 일부 캡션은 약 12px이며, 탭 전환 후에도 관측과 같은 가독성 기준인지 확인이 필요하다.
- **사용자 영향:** 화면 전환 후 주 정보는 찾을 수 있지만, 안내문과 보조 라벨이 관측보다 작게 느껴질 수 있다.
- **목표:** 기존 페이지 구조와 터치 크기를 보존하고, 과도하게 작은 보조 글자가 남는지 재검토한다. 실제 문제가 없으면 불필요한 광범위 변경은 하지 않는다.
- **상태:** 수정 전.

### 변경 요약

- 문제 상태에만 복구 CTA를 강조하고 정상 상태의 연결 버튼은 기본 조치처럼 보이지 않도록 중립화했다. CSS 상태 선택자만 추가했으며 계약 상태 계산·행동·기능 코드는 변경하지 않았다.
- 관측 상태/보조 텔레메트리의 글자 크기를 올리고 상태 레일을 소폭 넓혔다. 행 패딩을 함께 줄여 8개 항목을 모두 한 화면에 유지했다.
- 기존 5개 페이지 구조, 조작, 상태 항목 순서·심각도·행동 의미와 정직 문구는 그대로 두었다.

### 기능 스모크 테스트

- 내비게이션으로 다섯 화면 전환, 정상/문제/비행 없음 전환.
- MOP 연결 예시: `연결 중`/주의로 전환한 뒤 `[SIMULATED]` 하트비트 예시 정상으로 끝나며 실제 하트비트 수신이 아니라는 토스트 확인.
- 임무 사이트 동기화 요청은 실제 서버 호출이 없다고 표시.
- 검토에서 비행·사건 이동 및 오탐 의심 의견 추가/append-only 확인.
- 증거 업로드 요청은 실행되지 않고 미동기화 3건 유지; 서버 상태는 알 수 없음.
- Core 저장은 입력을 저장·전송하지 않음; Demo tick은 격리된 로컬 시연만 갱신.

### 정적 확인

- `field-shell.html` 외부 CSS/JS 의존 없이 단일 파일 유지. 파일명 유지.

- 보존 문자열 `사건 0건 — 정상 기록일 수 있음 / 안전 확인 아님`, `[SIMULATED]`, `RC 수신시각(근사)`, `미동기화 3건` 유지.
