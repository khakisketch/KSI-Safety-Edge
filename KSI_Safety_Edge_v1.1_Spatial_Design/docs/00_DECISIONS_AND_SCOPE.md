# 00. 결정·가정·범위 원장

상태: DRAFT. 대화에서 사용자가 지지한 설계 방침과 실기 검증을 기다리는 구현 가정을 분리한다. 기재된 `결정`은 **새 실험 버전의 제품 설계 기준**이고, 기존 운영 저장소 설정 변경 승인으로 간주하지 않는다.

## A. 설계 기준선 (DECIDED FOR EXPERIMENT)

| ID | 결정 | 강제하는 결과 |
|---|---|---|
| B-01 | Matrice 4E/4T + Manifold 3(PSDK) + RC Plus 2(KSI MSDK) | 장비 의존성을 Capability Matrix로 관리 |
| B-02 | PSDK/Manifold가 영상+텔레메트리의 실시간 수집/정합/1차 AI 책임 | GB10의 RC/영상 별도 정합을 실시간 필수경로에서 제외 |
| B-03 | MSDK는 임무/위험구역 작성·적용·현장 표시·로컬 저장 책임 | 인터넷 없는 현장에서 전체 비행 수행 가능 |
| B-04 | PSDK의 서버 직접 업로드는 **지원가능성 여부와 무관하게 구현·운영 안 함** | PSDK의 egress 비활성, 승인된 MOP 전송만 사용 |
| B-05 | 서버 업로드는 RC에서만 시작. 인터넷 가용할 때 재시도 | wifi/테더링/4G가 없으면 로컬 보관 |
| B-06 | 웹은 현장·위험구역 관리, 사건 증거/조치 관리. 실시간 웹관제 기본 제외 | 서버 필수는 API/데이터이고 웹은 최소 업무 UI |
| B-07 | 외부 Agent가 API/MCP로 현장 안전 데이터를 조회/분석 | 자체 채팅 UX 개발은 기본 제외 |
| B-08 | DGX Spark는 선택적 **비행 후 배치** 오탐 의심·미탐 후보 검토 | 실시간 판단을 서버 VLM 응답에 의존 금지 |
| B-09 | 조종사는 승인 강제 없이 오탐 의심/확인 필요만 표시 | 탐지 원본 삭제 금지, 의견은 분리 |
| B-10 | 위험구역은 서버와 RC 양방향 편집하되 비행마다 불변 Snapshot | 사건의 당시 판단 조건 복구 가능 |
| B-11 | 사건 없는 비행도 저용량 영상, 궤적, AI 가동·미관측 기록 보존 | 미탐 탐색과 점검 커버리지 가능 |
| B-12 | 기체 SD 고품질 파일은 별도 취득 경로 | RC 저용량 영상이 원본 고품질의 대체 아님 |

## C. v1 범위 / 미포함

**P0 반드시 포함**
- 오프라인 현장/임무/버전 캐시; 웹·RC 위험구역 동기화 및 충돌 감지.
- Edge telemetry/video intake/정합 상태/사람·기본 PPE 1차 탐지, 탐지 결과, 위치 확신이 없을 때 정직한 보류.
- MOP 양방향 명령/ACK/결과 재전송, RC 라이브 영상·경고, RC 저용량 비행 영상/이벤트/궤적 로컬 기록.
- 업로드 큐와 해시 검증/서버 ACK/재전송, 불변 증거·사건 및 피드백 기록.
- 서버 조회 API, 사건/구역/비행 기록, 최소 웹 및 API/MCP read-only 질의.
- 미관측/영상 공백/AI 비가동 품질 정보, 실기 합격 게이트.

**P1 첫 검증 이후**
- 시설별 조치/검토 워크플로, 사후 VLM batch, 고품질 원본 자동 가져오기, 관측 커버리지 정량화 강화, 보고서.

**P2 장기 후속**
- Dock/Cloud API 수집 어댑터, RC 자체 경량 추론 대체 모드, active perception/자동 재관측, 고객별 모델학습 및 롤아웃.

**명시 제외**
- PSDK→서버 직접 업로드, 상시 GPU inference, 실시간 웹 영상 재송출, 자동 위험 확정·법적 준수 보장, 자동 비행/짐벌 제어 폐루프, 무검증 위험구역 지면투영, 모든 사건 승인 강제, 오탐 원본 삭제.

## D. 범위 조정 원칙

P0 수정은 `DECISION_LOG`에 이유, 데이터 계약 영향, 롤백 방법을 남긴다. 새로운 모델·화면은 사유와 KPI 없이 P0에 추가하지 않는다. 출시 게이트의 임계값은 추정치가 아니라 현장 실측으로 확정한다.
