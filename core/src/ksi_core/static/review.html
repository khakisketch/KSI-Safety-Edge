Core에 내장된 정적 페이지입니다 — 데이터가 미리 심겨 있지 않으며, 조회는 아래에 붙여넣은 읽기(read) 토큰으로 기존 조회 API만 호출합니다. 안전관리자 오탐 의견 작성은 별도 작성(rc 스코프) 토큰을 넣은 경우에만 기존 append-only 주석 API로 전송됩니다 (삭제 없음 — 취소는 REVOKE_PREVIOUS 새 기록). 운영 배포 전 사용자 인증·권한·HTTPS는 별도 보안 게이트입니다.
토큰은 이 브라우저 탭(sessionStorage)에만 저장됩니다. 저장소·서버에 기록되지 않습니다.
