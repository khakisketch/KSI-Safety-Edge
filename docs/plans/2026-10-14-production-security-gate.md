## 게이트 표

| # | 게이트 | 현재 상태 | 통과 기준(검증 방법) | 막는 것 |
|---|---|---|---|---|
| G1 | 전송 보안(HTTPS·평문 축소) | **부분 구현(2026-10-14)** — 릴리스 `network_security_config`=평문 금지, 디버그(개발·실기)만 허용(빌드 산출물 dump 검증) | 운영 Core HTTPS 엔드포인트·인증서 확정 + 릴리스 APK에서 평문 차단 재확인 | 운영 Core 통신 |
| G2 | 인증·권한 | 미구현 — dev 정적 토큰(read/write 분리)만 | 토큰 발급·회수·회전, 조직 스코프, 최소 권한, 감사 로그, 만료 정책 | 모든 운영 사용자 |
| G3 | 검토자·조종사 신원 | 미구현 — annotation `actor_id`=uuid, 이름은 기기 로컬 | 조직 디렉터리 연동(actor uuid 해석), 조종사 이름 서버측 해석, 역할별 검토 권한 | S2 검토 여정 |
| G4 | 비밀·토큰 저장 | 구현 — Keystore AES-GCM envelope, 평문 1회 마이그레이션, 오류 표시 | A9-4 실기: 저장→재시작 복원→오류 경로 캡처 | RC 현장 사용(부분) |
| G5 | 데이터 보존·백업·복원 | 미정 — 정책 없음 | 보존 기간·삭제·백업/복원 절차와 실제 복원 검증(테넌트 분리 유지) | 운영 데이터 관리 |
| G6 | 알림(S2) | 미구현 | S2 착수 시 별도 설계·검증 | 검토 알림 |
| G7 | 배포 산출물(서명·버전·롤백) | 미구현 — debug 빌드만 | 릴리스 서명 키, 버전 정책, 롤백 절차, 스크럽 체크 자동화 | 설치·업데이트 |

## 결정 필요 (사용자/운영 입력)

- G2: 인증 방식(IdP·사내 계정·토큰), 조직·역할 구조, 토큰 수명.
- G5: 보존 기간, 백업 주기·보관 위치, 삭제 요구(개인정보 포함 여부).
- G1: 운영 Core 도메인·인증서(HTTPS), 사내망/Tailscale 경로와의 관계.
- G7: 릴리스 서명 키 관리 주체.

## 불변 원칙 (게이트 진행 중에도 유지)

- RC가 유일한 업로드 주체. 서버 `COMMITTED`만 동기화로 표시(read/write 토큰 분리 유지).
- 게이트 미통과 상태를 "완료"로 표기하지 않는다. dev 토큰·데모 DB를 운영 경로로 승격하지 않는다.
- Funnel(공개)에 검증 도구·콘솔을 노출하지 않는다(`docs/verification/dev-harness-runbook.md`).
