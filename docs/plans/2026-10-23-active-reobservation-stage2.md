# 능동 재관측 — 2단계 독립 검증 계획 초안

상태: **2026-10-23 모의 포트 기반 코어 개발 승인·진행 중. 실제 카메라 제어·SDK 교체·PPE 위험 경보 승인 아님.**
상위 계획: [1단계 자동 관측](2026-10-23-autonomous-observation-stage1.md).
보호 범위: RC/기체/Manifold 접근 금지 유지, 동결 계약·기존 증거·작업 트리 보존.

## 1. 검증 질문과 범위

안전모 의심 대상에 대해 **추가 관측이 유용한지 판단하고, 허용된 화각 변경 뒤 같은 대상을
다시 식별할 수 있는가**를 검증한다. 안전모 미착용 위험을 확정하는 시험과는 다르다.

1단계의 사람–중장비 공간 평가에 이 기능을 필수 의존성으로 넣지 않는다.
첫 구현은 모의 카메라·명시적 시험 자료만 사용한다. PPE 관측 자료/모델은 출처·버전·한계를 특정한다.
해당 자료/모델이 없으면 제어/재식별 모의 시험으로 제한하고 실제 PPE 분석으로 주장하지 않는다.

## 2. 관측과 제어의 독립 상태

| 축 | 정본과 의미 |
|---|---|
| AI 관측 실행 | 실제 처리·입력 품질 근거. 수동 카메라 조작으로 전체 관측을 중지하지 않음 |
| 자동 카메라 허용 | 사용자가 허용한 범위·기간·실행 세대. 허용은 실제 제어 중이라는 뜻이 아님 |
| 카메라 제어 주체 | 실제 장치 보고/검증된 중재 근거. 조종자·DJI 임무·KSI·미확인 구분 |
| 재관측 작업 | 계획·요청·거절·수행·중단·만료·결과 미확인. SDK ACK와 실제 결과 구분 |
| 대상 연결 | 원 대상과 재관측 대상의 연결 근거·신뢰도·모호성. 추적 ID만 같다고 확정하지 않음 |

자체 중재기는 KSI 내부 요청을 통제할 뿐, DJI 임무/물리 RC의 실제 우선순위를 증명하지 않는다.
실제 수동 개입과 중단을 검증할 수 없는 조합에서는 능동 조절을 허용하지 않는다.

## 3. 제한된 작업 흐름

```text
재관측 필요성/효용 평가
  → 대상 최신성·남은 관측 시간·권한·임무 카메라 충돌·보존 가능 여부 확인
  → 불필요/불가이면 사유 기록하고 기본 관측 지속
  → 허용된 조작을 단일 중재기에 요청
  → ACK와 별도로 실제 카메라 상태·안정화·새 프레임 확인
  → 대상 재식별
  → 연결 가능/모호/실패 결과와 원본 보존
  → 허용이 유효한 경우에만 다음 관측 단계로 이동
```

- 행동 집합은 승인할 카메라/짐벌/줌·촬영 기능으로만 한정한다. 각 기능의 지원은 개별 검증한다.
- 모든 후보에 줌하지 않는다. 효용이 없거나 주변 관측을 해치면 수행하지 않는다.
- 시간·시도·화각/속도·증거 용량 예산을 유한하게 둔다. 숫자는 실제 입력/장치 측정 뒤 확정한다.
- 기체 이동·고도·경로 변경이나 순찰 정지/취소를 요청하지 않는다. 대상이 시야를 벗어나면 추격하지 않는다.
- 권한 세대와 작업 식별자로 지연 ACK/콜백/큐 요청을 차단한다. 중단된 작업을 재전송으로 부활시키지 않는다.
- 수동 카메라 조작 후 자동 허용은 명시적으로 다시 부여한다. 원래 화각 복귀도 수동 조작을 덮어쓰면 안 된다.
- 실제 영상/상태가 오래됐으면 능동 조절을 중지·보류한다. 수신되는 영상의 가능한 분석은 별도로 계속한다.
- 링크 유실 때 수동 개입 감지가 보장되지 않으면 자동 카메라 허용을 보수적으로 만료시키는 안으로 시험한다.
  무감독 능동 제어를 계속하는 정책은 별도 승인 대상이며, 기본 로컬 관측 지속과 합치지 않는다.
- 입력 프레임이 오지 않아도 작업 마감·권한 만료가 동작해야 한다. 재부팅은 증거만 복구하고 실행/권한은 복구하지 않는다.

## 4. 모의 시험과 실기 시험

| 시험 | 합격 근거 |
|---|---|
| 재관측 효용 없음 | 카메라 요청 0건, 사유와 기본 관측 지속 이력 |
| 정상 확대/짐벌 변경 | 실제 상태를 모의한 새 관측과 원본 연결. 명령 ACK만으로 성공 처리하지 않음 |
| 요청 거절·상태 유실·안정화 시간 초과 | 실패/미확인으로 마감, 한도 없는 재시도 없음 |
| 수동 개입 중 지연 콜백 | 새 카메라 요청 없음, 과거 작업 복원 없음, 분석 가능한 영상 처리 지속 |
| DJI 임무가 카메라를 사용하는 모의 구간 | 충돌 요청 억제. 모의 우선순위를 장치의 보장으로 주장하지 않음 |
| 대상 소실·화각 전환·비슷한 다른 사람 | 연결 모호성을 기록, 다른 사람을 원 대상으로 확정하지 않음 |
| 줌 후 보정/자세/시각 근거 부족 | 해당 공간 판단 보류, 확대했다고 거리가 검증된 것으로 처리하지 않음 |
| 링크 단절·재부팅·용량 실패 | 권한·작업 중단과 관측/증거 실패 범위 분리, 기존 원본 보호 |

모의 합격 뒤에만 장치별 카메라 지원, 수동/임무/PSDK 명령 우선순위, 실제 중단 지연,
렌즈·자세·프레임 정합, 화각 변경 후 대상 연결과 관측 공백을 실제 M4D에서 검증한다.
장치 작업은 현재 보류 상태이며 별도 접근 허용·공식 설치 조건 충족 전 실행하지 않는다.

PSDK 3.16.0 고정본과 최신 버전 차이는 자산 원칙에 따라 비교한다. 자동 업그레이드하지 않는다.
API 존재·지원 제품 목록·모의 합격만으로 개별 조합의 동시 운용을 보장하지 않는다.

## 5. 결과의 경계

산출물은 Action·대상 연결·증거·실패/공백 이력이다. 자동으로 사람의 확인 기록을 만들지 않는다.
재식별 성공은 안전모 판별 성공도, Incident/위험 Alert 승인도 아니다.
주요 지표는 필요한 재관측의 성공/불가 사유, 대상 연결 오류, 관측 공백·자원 사용,
수동 양보의 실제 결과다. 카메라 이동 횟수나 자유도를 성공 지표로 삼지 않는다.
