# 통합 개발 검증 결과 — 2026-10-20

상태: **핵심 수직 경로 코드 반영·호스트 검증. 장비 실행·네이티브 UX·L1 인수·제품 전체 완료 아님.**
정확한 대상별 결과·산출물 SHA-256·현재 소스 해시는 같은 이름의 `.json`에 기록했다.
작업 트리에는 보존한 선행 미커밋 변경이 포함되어 있으며 해시 목록은 저작/변경 주체 목록이 아니다.

## 반영한 흐름

1. 실제 서버 번들 또는 저장된 불변 구역의 RC_LOCAL·SHADOW 번들 구성 → 검증·적용 요청.
2. Manifold 엔진의 실제 설치 결과·모델 digest·설정 해시 대조 → 명시 시작 → 실제 처리/입력 상태 보고.
3. MOP 단절 중 영속 큐·원래 ID/순번/출처 유지 → 재접속·재시작 회수 → RC 영속 수신 ACK.
4. 실제 STOPPED 또는 명시적 미확인 RC 기록 마감 → 영상/연계·쓰기 실패·대응 0건까지 마감 원장에 보존.
5. 필수 파생 아티팩트 생성 후 종료/업로드. 커밋 영수증은 로컬에 저장한 뒤에만 완료로 표시.
6. 구조화 대응 배치·Core 조회·읽기 전용 대조까지 연결. 늦은 대응은 기존 아티팩트 COMMITTED 뒤에도 동기화.

## 실패 경로 보강

- START/STOP 수신 순서, APPLY 동시 도착, 재시작 시 새 실행 식별자·재검증, 과거 RUNNING 자동 복원 금지.
- 실제 설치 전 APPLIED/출처 승격 금지, 잘못된 번들·해시·세대의 보고는 진단으로만 보존.
- 렌더마다 확인시각 갱신·판정 반복 저장 제거. 선택 후보의 실제 사건별 시각/boot만 사용.
- 디스크 실패 시 메모리 인덱스/중복 제거/영수증이 영속 기록보다 앞서지 않도록 변경.
  부분 꼬리 복구·실패 쓰기 롤백·복구 불가능 시 쓰기 차단·counter 원자 교체/엄격 파싱 시험.
- 저장소 장애는 KSI 새 기록·ACK·완료 주장을 차단하되, 기본 기체/영상·카메라 UI 초기화를 죽이지 않도록 격리.
  읽을 수 없는 로그의 unavailable holder는 임시 디렉터리나 파일을 만들지 않는다.
- Edge audit는 작업/boot별로 분리·복구하고 내용이 달라지면 새 아티팩트 ID를 사용한다.
  저널 실패 전에 정상 적용/발행을 주장하지 않으며, 고갈/감사 이력 손실은 DEGRADED·세션 실패 근거다.
- ACK된 전송 payload만 digest tombstone으로 압축. 미ACK 자료·RC 미업로드 증거·원본 audit를 자동 삭제하지 않는다.
- 인자 없는 DPK 실행은 기본 MOP 0 서비스 대기·기본 종료기한 없음·자동 분석 없음.
  standalone 진단은 명시 선택·유한 시간이며 실제 엔진 경로/모델 ID는 신뢰된 초기 배포 입력이다.
- 현대 실행 보고의 설치 해시 부재는 미확인이다. legacy bool의 protocol STOPPED는 실제 중지 완료 증명이 아니다.
- 처리 카운터만 있고 관측 원문이 없으면 깨끗한 탐지 0건이나 SUCCESS로 취급하지 않는다.
  알려진 영상 쓰기·증거 영속 실패는 서버 보존 성공으로 상쇄하지 않는다.

## 2026-10-21 추가 — 실기 RC 네이티브 렌더

실제 RC Plus 2가 tailscale 경유 네트워크 ADB(`100.67.37.51:5555`)로 열려 있어, 네이티브 화면을
**실제 기기에서** 확인했다(768×480dp 실측). 이 과정에서 호스트 시험으로는 보이지 않던 결함 4건을
수정했다(명령 데크 22px→246px 압축, 버튼 3열→2열, 현장 카드 위치, 위치 권한 중복 선언).
상세: `docs/plans/2026-10-21-screen-contract.md`, 증거: `docs/verification/evidence/2026-10-20-rc-native-render/`.

- **실기로 확인됨**: 첫 화면=관측, 연결 헤더 1줄 + 3단 상세, 현장 확인 카드, '관측 기록' 페이지와
  동기화(유실 확인) 영역, 라이트/다크, 명령 데크 스크롤, 2열 명령 버튼.
- **여전히 미검증**: DJI SDK 등록(우리 패키지 키 부재), 기체·영상 실물, Manifold 실기 왕복,
  햇빛·장갑 터치, 관측 세션 실데이터, GPS 추천 결과(현장 좌표 미등록).
  실기 렌더는 bench flavor(가짜 링크)다.

## 정정과 미완료

- 빈 Demo/프레이밍 자료를 제품 전체 입력으로 일반화한 설명은 정정했다. 실제 서버 번들 경로는 기존에도 있다.
- 재사용 감사·frame_queue/PSDK 글루 채택 이력도 기존 자산이다. 스키마 공유만이 유일한 재사용 방식은 아니다.
- PSDK 호스트 빌드 불가라는 단정은 철회했다. 다만 호스트 ABI·TensorRT OFF 빌드가 Manifold 배포/실행을 보증하지 않는다.
- 현재 ADB 장치·DJI 키 파일이 없고 Manifold SSH는 no route다. 실제 MOP·장시간 부하·단절/재접속·파일시스템,
  기체 명령·영상 표시/재생·native 글자/터치/장갑/햇빛 검증은 A9-4에서 해야 한다.
- 새 지도 편집·현장 좌표/보정/노출시각 연결·위험구역 판단 정확도·규칙별 ACTIVE·운영 인증/보존/서명은 미완료다.
  다중 Edge boot에 걸친 RC 영상의 확정 연계가 없으면 로컬에 남기고 검증된 증거로 승격하지 않는다.
- 첫 화면을 비행 화면 기반으로 바꾸고 GPS로 현장을 추천/확인하는 방향은 **제안**이다. 이번 코드에 자동 확정하지 않았다.
- 기존 `PRODUCT.md`·`DESIGN.md`의 일부 보조 앱/Pilot 2 문구는 최신 주 운용 앱 결정 이전의 디자인 문맥이다.
  이번 마감에서 임의로 재생성하지 않았다. 현재 책임·기능·안전 경계는 `docs/product-state.md`와 현행 운용 계약을 우선한다.
- 기존 스키마·예제·기본 OpenAPI 바이트를 보존했고, 신규 operator-response 스키마/예제와 별도 확장 API를 추가했다.
  새 API를 숨기지 않고 기본+확장의 정확한 합집합으로 검사한다. Core 저장은 현장 전달/수신/조치 완료와 별개다.

커밋·서명 키 생성·실장비 설치/조작은 하지 않았다.
