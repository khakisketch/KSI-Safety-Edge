# 기존 모델·DJI 업체 사례의 도입 전 확인 — 2026-10-27

상태: **공개 자료와 기존 측정 기록의 검토**. 모델·업체를 선정하거나 제품 사용을 승인한
것이 아니다. 기체 연결, 현장 자료의 외부 전송, 모델 다운로드·학습·구매는 하지 않았다.

사용자가 동의한 방향은 DJI 기본 감지와 이미 확보된 모델을 먼저 비교하고, 부족한 대상이
확인되면 외부 모델을 검토한 뒤 필요한 경우에만 파인튜닝하는 것이다. Manifold의 독립
관측·증거화와 RC 연결 단절 시 동작은 그대로 유지한다.

## 후보별 현재 사실과 미확인

| 후보 | 확인된 사실 | 도입 전 남은 확인 |
|---|---|---|
| DJI 기본 자동 감지 | MSDK 5.18 문서에 자동 감지의 대상 목록·유형·영역 인터페이스가 있다. | 사용자 장비·펌웨어의 지원 클래스와 다중 대상, 시간 정합, 실제 정확도, Manifold 독립 경로 및 오프라인 동작. API의 존재는 실기 작동의 증거가 아니다. |
| D-FINE-S COCO | Manifold 측정 (실측 원본 비공개 보존)은 장치의 사전 준비된 엔진과 참조 입력에 대해 실행·비교를 기록한다. | 기체 라이브 카메라 입력, 현장 정확도, 실제 배포 산출물의 계보·권리 및 평가 조건. 해당 측정은 현장 인수가 아니다. |
| 기존 PPE 후보 | [기존 후보 기록](2026-10-27-next-models.md)은 `yolo26_ppe.onnx`의 장치 TRT 빌드와 추론 시간, 현장 정확도 미검증을 기록한다. | 실제 ONNX의 출처·가중치·변환 계보·정확도·전체 라이선스. 해당 기록의 MIT 표기만으로 제품 사용 가능 판정을 하지 않는다. |
| DJI 업체 사례 | DJI 공식 AI 개발자 페이지는 안전모 탐지와 GDDi 건설 중장비 탐지를 **업체 사례**로 소개한다. | 구매·제공 가능 여부, 대상 기체·펌웨어, 배포·오프라인·SDK 결과 접근, 가격·라이선스, 서비스 지속성과 우리 조건의 독립 검증. 사례 소개는 기본 내장·무료·검증 완료라는 뜻이 아니다. |

기존 D-FINE 측정의 엔진과 참조 입력은 당시 Manifold에 사전 준비된 자료다.
[`edge/README.md`](../../edge/README.md)는 가중치·참조 영상이 이 저장소에 추적되지
않는다고 명시한다. 기체·Manifold를 연결하지 않은 이번에는 해당 측정을 재실행하지 않았다.

## PPE 후보의 라이선스는 별도 게이트

- 기존 기록이 가리키는 [Hansung-Cho 모델 카드](https://huggingface.co/Hansung-Cho/yolov8-ppe-detection)는
  공개 revision `ac0027bd38bc619d5ce4f52b4cc01beb87d8b958`에서 MIT를 표기하고,
  기반 모델을 **Ultralytics YOLOv8n**으로 설명한다. 데이터셋 라이선스는
  각 제공처를 따르며, 저자는 낮은 해상도·가림 등에 대한 한계와 생명안전 단독 판단 금지를 명시한다.
- [Ultralytics 라이선스 안내](https://www.ultralytics.com/license)는 자체 코드·모델과
  학습 모델의 사용에 대해 AGPL 또는 Enterprise 조건을 설명한다. 이는 공급자의 안내이며,
  개별 산출물의 법적 결론이나 이 프로젝트의 의무를 확정하는 문구가 아니다.
- `yolo26_ppe.onnx`라는 기존 기록의 파일명과 위 YOLOv8 모델 카드만으로는 **실제 산출물이
  어느 가중치·코드·데이터로 만들어졌는지 독립적으로 입증할 수 없다**. 제품 채택 전 원본
  가중치의 출처·버전·해시, 변환 코드·도구·버전, 최종 ONNX/엔진 해시, 데이터와 각 의존성의
  권리·상용 배포 조건을 확인하고 필요한 법률/권리자 검토를 거친다.
- 따라서 앞선 후보 기록의 `MIT ✅`는 **모델 카드의 표시를 확인한 사실**로 한정한다.
  모델 자체, 기반 프레임워크, 학습 데이터 및 변환 산출물 전체의 상용 권리 승인은 아니다.

## 업체에 확인할 질문 (문의 전 초안)

실제 문의·계정 생성·약관 동의·자료 업로드는 하지 않았다.

1. Matrice 4D의 해당 세부 모델과 펌웨어에서 사용할 수 있는가? 실제 인식 대상과 동시 실행 가능한 모델은 무엇인가?
2. Pilot 2 화면 외에 **KSI MSDK 앱과 Manifold PSDK 앱이 각각** 어떤 구조화된 결과를 받을 수 있는가?
   대상 종류·영역·시각·대상 식별자와 그 유효 범위도 제공되는가?
3. 최초 등록·갱신과 현장 추론 각각에 인터넷이 필요한가? RC 연결이 끊겨도 Manifold가 결과와 원본을 확보할 수 있는가?
4. 도입 비용·기체별 라이선스·기간·재배포·업데이트·서비스 종료 조건은 무엇인가?
5. 현장 영상·모델·기체 식별정보를 누구에게 제공해야 하며 보관·삭제·국외 이전 조건은 무엇인가?
6. 현장 데이터 평가·오탐/미탐 검토와 독립 테스트에 필요한 자료를 제공할 수 있는가?
